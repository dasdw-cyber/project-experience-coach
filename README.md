# 个人项目梳理 · Project Experience Coach

把零散的项目经历，整理成讲得清楚的项目过程和能直接使用的简历文字。

[查看完整规则](SKILL.md) · [查看输出格式](references/output-formats.md)

## 这是什么

做过一个项目，真正写简历时，却只写出了“参与项目开发”“负责数据处理”。

翻开报告，里面有背景、方法和结果；问起自己具体做了什么，又不知道从哪里讲起。

这个 Skill 帮你从已有材料或零散回忆开始，理清项目过程、个人分工、关键选择和结果，最终形成两份可以继续使用的材料：

- **完整项目整理**：保留项目推进过程，供自荐信、导师筛选和面试准备使用。
- **简历版项目经历**：提炼具体工作、方法和产物，适配简历表达。

> 先把项目过程理清楚，再把个人贡献写具体。

## 效果示例

以下为虚构示例，展示同一组事实怎样从口述变成简历文字。

**整理前**

> 我参加过一个食堂排队调查，和队友一起做问卷。我主要清理空白和重复记录，再按食堂、时间段做统计和图表，交给负责建模的同学。

**整理后**

**校园食堂排队调查与分析** ｜ 项目成员 ｜ 起止时间待补

- **调查设计**：与队友共同设计排队情况问卷，统一食堂与时间选项，支持不同场景下的数据整理与比较。
- **数据清洗**：检查并删除空白及重复提交记录，整理后续统计所需的数据表。
- **统计分析**：按食堂与时段汇总调查数据、制作分组图表，向负责建模的队友交付数据与分析结果。

完整整理还会保留项目背景、各步骤的衔接、本人分工和结果依据，方便后续按不同用途改写。

## 快速开始

下载本仓库，保留 `SKILL.md`、`references/`、`assets/` 和 `agents/` 的目录关系，在支持 Skill 的 AI 助手中加载。

支持按名称调用时，可以这样开始：

```text
请使用 $project-experience-coach，帮我梳理一个个人项目。

我的项目报告和答辩 PPT 在〔文件位置〕。
请先读取材料，给出整体梳理，再每轮补问一个关键问题。
最后输出完整项目整理和简历版项目经历。
```

也可以让具备本地文件读取能力的 AI 直接读取 `SKILL.md`，按其中的方法开始。

没有现成材料时，先说一两句你记得的工作即可。

## 怎样帮你理清经历

1. **先读材料。** 从报告、PPT、简历或已有文字中提取事实。
2. **先给整体梳理。** 整理“要解决什么—做了哪些步骤—目前有什么结果”。
3. **逐轮补齐缺口。** 每轮默认一个关键问题，逐步澄清分工、方法选择和验证。
4. **形成两种输出。** 完整版保留过程，简历版精选重点，两版事实保持一致。

STAR 用于助手后台组织事实。你可以用口语和片段回答，助手负责整理。

## 核心特点

- **材料优先**：已有信息直接复用，提问围绕实际缺口展开。
- **贡献具体**：分清团队工作、本人任务和实际完成的行动。
- **过程连贯**：说明方法怎样衔接、为什么采用、怎样检查结果。
- **结果有依据**：保留验证条件、单位和项目阶段；没有数字时写具体产物。
- **简历格式明确**：包含项目名、角色、起止时间，每点使用加粗的四字或五字工作标签。

科研、竞赛、课程设计、毕业设计和实习任务都可以整理。论文、奖项和量化指标均非使用门槛。
