# 个人项目梳理 · project-experience-coach

帮助你把零散的科研、竞赛、课程设计、毕业设计或实习经历理清楚，再写成完整项目整理和简历版项目经历。

有报告、PPT、简历等材料时，AI 先读取，再针对缺口补问；没有材料时，从一句粗略描述开始。你不必先想好创新点，也不必一次填完问卷。

## 怎么使用

这是供 AI 助手读取的 Skill，不是独立运行的软件。使用环境需要能读取 Markdown 文件；读取本地项目材料还需要相应的文件访问能力。

下载本仓库，保留 `SKILL.md`、`references/`、`assets/` 和 `agents/` 的目录关系。在支持 Skill 的工具中，按该工具的方式加载本目录；也可以直接让能读取本地文件的 AI 助手读取 `SKILL.md` 后开始。

支持按名称调用的环境中，可以使用：

```text
请使用 $project-experience-coach，帮我梳理一个个人项目。
先问我有没有现成材料，再根据实际缺口逐步引导。
```

也可以直接这样开始：

```text
请先读取这个目录里的 SKILL.md，并按其中的方法帮我整理项目。
我有一份项目报告和答辩 PPT，可以提供文件位置。
```

没有材料也可以：

```text
请先读取这个目录里的 SKILL.md。我没有整理好的材料，
只记得参加过一次校园数据分析比赛，主要做问卷和数据清理，
最后交了方案、参加了答辩。请先帮我理清项目过程。
```

## 使用过程

1. **先看材料是否可用。** 已提供文件、路径或正文时直接读取，不重复询问。
2. **先给整体梳理。** 根据已知信息整理“要解决什么—做了哪些步骤—目前有什么结果”，不明确的连接标为待补。
3. **每轮补一个关键问题。** 先理顺项目过程，再逐步澄清个人分工、方法选择和验证；已有信息不重新采访。
4. **形成两种输出。** 同一组事实分别组织为完整整理和简历版，名称、角色、时间及结果条件保持一致。

STAR 是 AI 后台组织事实的方法，不要求你按四个字母逐项回答。没有论文、奖项或量化指标，也可以从真实完成的工作和产物开始。

## 默认交付

### 完整项目整理

包含项目基本信息、背景与目标、本人任务、实施过程与关键选择、验证与结果、实际认识，以及一段连贯的详细项目叙述。来源和待补项单独记录。

### 简历版项目经历

项目头部包含项目名、本人角色和起止时间；正文按关键工作分点，每点以加粗的四字或五字中文短语开头，再写具体行动、方法、产物或结果。

以下仅为虚构格式示例：

**校园食堂排队调查与分析** ｜ 项目成员 ｜ 2025.03—2025.05

- **调查设计**：与队友共同设计排队情况问卷，统一食堂与时间选项，支持不同场景下的数据整理与比较。
- **数据清洗**：检查并删除空白及重复提交记录，整理为后续统计和建模使用的数据表。
- **统计分析**：按食堂与时段汇总调查数据、制作分组图表，向负责建模的队友交付数据与描述性分析结果，支持团队方案与答辩准备。

实际输出根据你的材料调整，不为凑齐结构补造工作、指标、获奖或个人贡献。需要时也可以只输出其中一种。
